## 风险清单

| 编号 | 等级 | 风险 | 当前处理 |
|---|---|---|---|
| R1 | S2 | PPG 质量受佩戴、肤色、压力、环境光影响 | 通过 SQI、主通道选择、低质量不输出处理 |
| R2 | S2 | 仅靠外部运动标志，无法识别所有微动伪迹 | 当前项目边界接受；必要时后续引入 PPG 质量门控 |
| R3 | S2 | ECG 与 PPG 存在生理延迟，beat-level 对齐可能有偏差 | M5 验证时重点看 IBI 误差，而非绝对峰位完全一致 |
| R4 | S1 | 若 timestamp 抖动很大，丢点阈值可能误触发 | M3 先实现可配置阈值，M5 根据数据调整 |
| R5 | S2 | RAM `<20KB` 限制下无法使用长窗口复杂算法 | M2 已冻结流式处理和短缓存策略 |
| R6 | S2 | 第一版主通道策略可能不如复杂融合鲁棒 | 先实现可测基线，再根据验证结果决定是否升级融合 |
| R7 | S0 | 如果上层要求无效时也输出保持值，将改变 API 语义 | 当前决策为无效时 `valid=false`，不输出旧 IBI；如要改变需 Owner 决策 |

## 当前无阻塞风险

M2 可以进入 M3。

M3 只实现框架，不触碰高风险算法核心，因此风险可控。
