# 08_OWNER_HANDOFF.md

## M1 完成后 Owner 要做什么

1. 将本项目包解压到空仓库。
2. 确认文档结构存在。
3. 告诉 Architect：项目包已放入仓库，可以进入 M2。

不需要现在运行 Codex。

## 后续进入 Codex 阶段时

Owner 给 Codex 的默认指令为：

```text
请读取 docs/10_CODEX_NEXT_TASK.md，并严格执行。
```

## 如果恢复已有项目

如果后续中断后恢复，需要提供：

1. Project Brief；
2. Decision Log；
3. 当前 Milestone；
4. Codex 最近输出；
5. Review Summary。

Architect 不应凭空继续。
