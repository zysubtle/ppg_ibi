# 05_VALIDATION_PLAN_DRAFT.md

状态：草案，待 M2 / M5 细化。

## 1. 已知验证资源

已有 ECG 真值，可用于验证 PPG-IBI 的准确性。

## 2. 验证目标

验证 PPG 计算得到的 IBI 是否与 ECG RR 间期一致。

## 3. 初步指标方向

| 指标 | 含义 | 状态 |
|---|---|---|
| MAE | PPG-IBI 与 ECG-RR 的平均绝对误差 | 待定义阈值 |
| Median AE | 误差中位数 | 待定义阈值 |
| P95 AE | 95 分位绝对误差 | 待定义阈值 |
| 漏检率 | ECG 有心搏但 PPG 未输出有效 IBI | 待定义 |
| 误报率 | PPG 输出心搏但 ECG 无对应心搏 | 待定义 |
| 覆盖率 | 可输出有效 IBI 的时间比例或心搏比例 | 待定义 |
| RAM 占用 | 算法核心 RAM 占用 | 目标 `<20KB` |

## 4. Beat Matching 待定义

M5 需要定义 ECG 与 PPG 心搏匹配方式。

待确认内容：

1. 匹配窗口大小；
2. 是否允许固定 PPG-ECG 延迟补偿；
3. 是否按峰值时间匹配，还是按 IBI 序列匹配；
4. 无匹配时如何计入漏检或误报；
5. 异常 IBI 范围如何剔除。

## 5. 初步验证流程

1. 读取 PPG 与 ECG 真值数据；
2. 按时间顺序逐点调用算法；
3. 收集每个有效 PPG-IBI 输出；
4. 将 PPG-IBI 与 ECG-RR 进行匹配；
5. 统计误差、漏检、误报、覆盖率；
6. 输出 per-file 报告和总体报告。

## 6. 当前不冻结内容

2. 具体 beat matching 窗口；
3. 数据文件格式；
4. 是否需要可视化图表；
5. 是否需要 MCU 端实时验收脚本。
